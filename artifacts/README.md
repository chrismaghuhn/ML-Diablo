# Lokale Artefakte

Smoke-Runs, Trajektorien, Checkpoints und Auswertungen werden hier lokal erzeugt. Der
Inhalt ist standardmäßig ignoriert und gehört nicht in Quellarchive. Rohtrajektorien
aus dem echten Spiel sind wegen Asset-/Datensatzfragen privat zu behandeln, bis eine
gesonderte Veröffentlichungsprüfung erfolgt ist.
